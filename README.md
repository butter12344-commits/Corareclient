# CorareClient

Purple-themed Fabric client-side utility mod for Minecraft Java 1.21.11.

## Included
- Right Shift click GUI
- Purple/dark custom GUI
- Toggleable watermark, FPS counter, coordinates, keystrokes and crosshair overlay
- Client-side only; no server plugin required

## Build
Requires Java 21. Run `gradle build` (or `./gradlew build` when a Gradle wrapper is available).
The distributable JAR will be in `build/libs/`.

## Install
Install Fabric Loader for Minecraft 1.21.11 and Fabric API, then place the CorareClient JAR in `.minecraft/mods`.

This is an original implementation and does not include Purxiy's proprietary code or assets.
